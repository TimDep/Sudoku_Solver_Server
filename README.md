# Sudoku Solver Server (Quarkus REST Backend)

This is the backend service that handles Sudoku puzzle solving via REST APIs. It can accept puzzle inputs, run the solver logic, and return the solved grid.  

## Features

- REST API to receive a Sudoku puzzle (e.g. as JSON)  
- Solve using algorithm / logic (not all the solving techniques are implemented) 
- Return solution or error response  
- Optionally support native packaging (via Quarkus)
